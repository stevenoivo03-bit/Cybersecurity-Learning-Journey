### Digital Logic
## Key take aways
** * Computer Language 
   * Binary System - The communication that a computer uses,also known as a base-2 numeral system
   * In computing terms binary are group into 8 numbers or bits, technically a bit is a binary digit
   * 8 bits make up a byte. Each byte can store one character, and we can have 256 possible values          thanks to the base-2 system.
** * Character Encoding
   * character encoding assigns our binary value to characters,so that we as humans can read them
   * the oldest standard character encoding used is ASCII, which represents the English alphabet,           digits, and punctuation marks. ASCII only used a 127 out of 256 characters 
   * UTF-8 the most prevalent encoding standard used today, it also lets us use a variable number of        bytes. It allows us to store a character in more than one byte and it’s built off the Unicode          standard.
   * RGB model uses just 8 combinations of zeros and ones to represent everything displayed on a            computer.
** * Binary uses electricity via transistors allowing electrical signals to pass through. If there’s        an electric signal it would be denoted as one if there isn’t it would denote as zero.
     * Logic gates - allow our transistors to do more complex tasks, like decide where to send                electrical signals depending on logical conditions
